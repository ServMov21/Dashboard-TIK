## 1. Edit & Clone Tugas (Akun Guru)

### Edit Tugas
- Tombol **Edit** (ikon pensil) ditambahkan di setiap kartu tugas
- Form edit mendukung seluruh field: judul, deskripsi, deadline, status, kelas target, rombel target, naskah mengetik, bobot penilaian
- **Jenis tugas tidak dapat diubah** setelah dibuat (mencegah kerusakan data pengumpulan)
- Lampiran lama ditampilkan dengan tombol ✕ untuk menghapus masing-masing
- Guru dapat menambah lampiran baru sekaligus
- Backend: `PUT /api/tugas/:id` kini mendukung multipart/form-data

### Clone Tugas
- Tombol **Salin** (ikon copy) ditambahkan di setiap kartu tugas
- Modal clone: pilih kelas tujuan (multi-pilih) dan rombel (opsional)
- Hasil salinan selalu berstatus **Draft** agar guru bisa review sebelum diluncurkan
- Backend: `POST /api/tugas/:id/clone`

## 2. Edit Data Siswa (Akun Guru)

- Tombol **Edit** di setiap baris tabel Data Siswa
- Modal edit mendukung: **Nama**, **Kelas**, **Rombel**, **Tanggal Lahir**
- Jika Tanggal Lahir diubah → password siswa **otomatis diperbarui** ke format `DDMMYYYY`
- Backend: `PUT /api/siswa/:id`

## 3. Perbaikan Dashboard Siswa — Penghitungan Tugas

Masalah sebelumnya: saat tugas dikunci/ditutup guru, statistik menjadi 0.

### Perilaku baru:
| Kondisi | Sebelum | Sekarang |
|---|---|---|
| Tugas dikunci guru | Total → 0 | Tetap terhitung ✅ |
| Tugas ditutup, siswa belum kumpul | Belum Selesai → 0 | Tetap terhitung ✅ |
| Tugas mengetik selesai | Tidak dihitung | Terhitung ✅ |
| Tugas dihapus guru | — | Tidak dihitung ✅ |

- **Total Tugas** = semua tugas pernah diaktifkan (`launch` atau `ditutup`), kecuali yang dihapus
- **Sudah Selesai** = file dikumpulkan + mengetik selesai
- **Belum Selesai** = Total − Selesai (tidak reset ke 0 saat guru menutup tugas)

## 4. Pemberian Nilai (Akun Guru — Detail Tugas)

Di halaman detail tugas, setiap baris siswa yang sudah mengumpulkan kini memiliki panel penilaian:

```
[Nama Siswa]  [Preview] [Download]
[✏ Nilai: _/100] [Keterangan (opsional)] [Simpan]
```

- Input **Nilai** (0–100, step 0.5)
- Input **Keterangan** (catatan opsional guru)
- Tombol **Simpan** — berubah menjadi ✅ Tersimpan setelah berhasil
- Nilai yang sudah disimpan tampil otomatis saat halaman dibuka
- Tugas **Mengetik**: nilai otomatis dari sistem, tidak perlu input manual
- Backend: `PUT /api/pengumpulan/nilai/:id`

## 5. Rekap Nilai (Akun Guru)

Menu baru **"Rekap Nilai"** di sidebar guru.

### Fitur:
- Filter kelas + rombel
- Tabel: `NAMA | KELAS | ROMBEL | TUGAS 1 | TUGAS 2 | ... | TOTAL | RATA-RATA | TITLE | PERINGKAT`
- Kode warna nilai: 🟢 ≥85 · 🔵 70–84 · 🟡 55–69 · 🔴 <55
- Statistik ringkas: Rata-rata, Tertinggi, Terendah, Sudah/Belum Dinilai
- Pencarian nama siswa
- **Export Excel** sesuai filter aktif:
  - Filter Kelas 6 → `rekap-nilai-kelas6.xlsx`
  - Filter Kelas 5 Rombel B → `rekap-nilai-kelas5-rombelB.xlsx`
  - Tanpa filter → `rekap-nilai-semua.xlsx`
- Kolom **Title** menampilkan title XP siswa

## 7. Sistem XP & Title

Title kini ditentukan berdasarkan **total XP** (bukan posisi rank). Siswa baru selalu mulai dari 🌱 ROOKIE.

### Komponen XP:

| Komponen | Default |
|---|---|
| Base (mengumpulkan tugas) | +80 XP |
| Bonus Nilai 70–79 | +20 XP |
| Bonus Nilai 80–89 | +40 XP |
| Bonus Nilai 90–99 | +70 XP |
| Bonus Nilai 100 | +100 XP |
| Early Submission (sebelum deadline) | +25 XP |
| Perfect Score Bonus | +70 XP |
| Bonus Guru (manual, maks) | +20 XP |

### 10 Level Title:

| Level | Title | Emoji | XP | Min Tugas |
|---|---|---|---|---|
| 1 | ROOKIE | 🌱 | 0 – 399 | — |
| 2 | SCOUT | 🎯 | 400 – 899 | — |
| 3 | EXPLORER | 🚀 | 900 – 1.499 | — |
| 4 | GUARDIAN | 🛡️ | 1.500 – 2.099 | — |
| 5 | RANGER | 🏹 | 2.100 – 2.699 | — |
| 6 | WARRIOR | ⚔️ | 2.700 – 3.299 | ≥ 15 tugas |
| 7 | COMMANDER | 🛡️ | 3.300 – 3.899 | ≥ 20 tugas |
| 8 | ELITE | ⚡ | 3.900 – 4.499 | ≥ 25 tugas |
| 9 | MASTER | 💎 | 4.500 – 4.999 | ≥ 30 tugas |
| 10 | LEGEND | 👑 | 5.000+ | ≥ 35 tugas |

### Pop-up Notifikasi:
- **Setiap login** → info title aktif + target berikutnya (satu kali per sesi)
- **Buka Rekap Nilai** → selalu tampil info title
- **Naik title** → 🎉 TITLE UP! + animasi
- **Turun title** → notif motivasi

### Aturan XP:
1. Satu tugas hanya memberikan XP satu kali
2. Re-upload tidak menambah XP
3. XP bisa dikoreksi guru melalui perubahan nilai
4. XP dihitung otomatis saat nilai disimpan guru
5. Guru bisa beri bonus XP manual (0–20 XP)

## 8. Leaderboard (Akun Guru & Siswa)

Menu baru **"Leaderboard"** tersedia di sidebar kedua akun.

### Dua Mode:
- **Berdasarkan Rombel** — filter kelas + rombel
- **Berdasarkan Kelas** — filter kelas saja

### Kolom Tabel:
`Rank | Nama | Kelas | Rombel | Title | Total XP | Rata-rata | Tugas | ≥90`

### Urutan Peringkat (5 kriteria tiebreaker):
1. Total XP terbesar
2. Rata-rata nilai terbesar
3. Jumlah tugas selesai terbanyak
4. Jumlah nilai ≥ 90 terbanyak
5. Mencapai XP lebih awal

### Fitur tambahan:
- Siswa melihat posisi dirinya **disorot** warna title
- Info XP yang dibutuhkan untuk naik title berikutnya
- Siswa auto-load leaderboard rombel sendiri saat membuka halaman
